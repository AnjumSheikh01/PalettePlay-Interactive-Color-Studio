# PalettePlay — Interactive Color Studio

Responsive React color studio to generate, edit, save, preview, and export palettes.

## Run on Windows PowerShell
1. Open this folder in VS Code.
2. Run `npm.cmd install`
3. Run `npm.cmd run dev`
4. Open the Vite URL printed in the terminal.

Features: random palettes, locked colors, color picker, hex editing, clipboard copy, LocalStorage saving, palette search, live preview, and CSS export. Saved palettes stay in this browser; there is no backend or cloud sync.
